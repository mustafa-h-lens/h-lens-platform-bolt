# دليل نظام استخراج البيانات بالذكاء الاصطناعي

## نظرة عامة

تم إعداد نظام استخراج البيانات بالذكاء الاصطناعي بنجاح! هذا النظام يستخدم Claude AI من Anthropic لاستخراج البيانات تلقائياً من:
- صور الهوية الوطنية السعودية (رقم الهوية)
- صور استمارة السيارة (رقم الاستمارة، ماركة المركبة، رقم اللوحة)

## الإعداد المكتمل

### 1. Edge Function ✅
- **الاسم:** `extract-document-data`
- **الحالة:** نشطة (ACTIVE)
- **JWT Verification:** مفعّل
- **المسار:** `https://akcpkjzfhtmurtwzyzhn.supabase.co/functions/v1/extract-document-data`

### 2. قاعدة البيانات ✅
تم إضافة الأعمدة التالية إلى جدول `vendors`:
- `extracted_id_number` - رقم الهوية المستخرج
- `vehicle_registration_number` - رقم الاستمارة
- `vehicle_brand` - ماركة المركبة
- `vehicle_plate_number` - رقم اللوحة

### 3. الواجهة الأمامية ✅
- صفحة اختبار في الإعدادات
- أزرار استخراج في صفحة تفاصيل المورد

## كيفية الاستخدام

### اختبار النظام

1. اذهب إلى **الإعدادات** من القائمة الجانبية
2. اختر تبويب **"اختبار الذكاء الاصطناعي"**
3. اختر نوع المستند (هوية أو استمارة)
4. ارفع صورة المستند
5. اضغط على **"بدء الاختبار"**
6. انتظر النتيجة (عادة 3-5 ثوان)

### استخدام النظام مع الموردين

1. اذهب إلى **الموردين** → اختر مورد
2. اذهب إلى تبويب **"البيانات الشخصية"**
3. اضغط **"تعديل"**
4. ارفع صورة الهوية أو الاستمارة
5. اضغط على زر **"استخراج البيانات بالذكاء الاصطناعي"** بجانب الحقل المطلوب
6. ستظهر البيانات المستخرجة تلقائياً في الحقول

## التحقق من إعداد ANTHROPIC_API_KEY

للتأكد من أن المفتاح تم إضافته بشكل صحيح:

### في Supabase Dashboard:

1. اذهب إلى مشروعك في Supabase
2. **Project Settings** → **Edge Functions** → **Secrets**
3. تحقق من وجود متغير بالاسم: `ANTHROPIC_API_KEY`
4. القيمة يجب أن تبدأ بـ `sk-ant-`

### إذا لم يكن المفتاح موجوداً:

1. اذهب إلى [console.anthropic.com](https://console.anthropic.com/)
2. سجّل الدخول أو أنشئ حساب جديد
3. اذهب إلى **API Keys**
4. أنشئ مفتاح جديد
5. انسخ المفتاح (سيبدأ بـ `sk-ant-`)
6. أضفه في Supabase Secrets باسم `ANTHROPIC_API_KEY`

## استكشاف الأخطاء

### إذا ظهرت رسالة "ANTHROPIC_API_KEY not configured"

**الحل:**
- تأكد من إضافة المفتاح في Supabase Dashboard → Project Settings → Edge Functions → Secrets
- تأكد من أن اسم المتغير بالضبط: `ANTHROPIC_API_KEY`
- بعد إضافة المفتاح، قد تحتاج الانتظار دقيقة لتحديث الإعدادات

### إذا فشل الاستخراج

**تحقق من:**
- جودة الصورة ووضوحها
- أن الصورة تحتوي على المستند بشكل كامل
- أن النصوص واضحة وغير مشوشة
- اتصال الإنترنت
- رصيد API في حساب Anthropic

### عرض السجلات (Logs)

لمشاهدة السجلات التفصيلية:
1. Supabase Dashboard → **Edge Functions**
2. اختر `extract-document-data`
3. اذهب إلى تبويب **Logs**
4. ستجد جميع الطلبات والأخطاء

## معلومات تقنية

### النموذج المستخدم
- **Claude 3.5 Sonnet** (claude-3-5-sonnet-20241022)
- أفضل نموذج للتعرف البصري على النصوص
- يدعم اللغة العربية بشكل ممتاز

### معدل الاستخدام
- كل استخراج يستهلك حوالي 1024 tokens
- التكلفة التقريبية: $0.003-0.005 لكل استخراج

### الأمان
- جميع الطلبات تتطلب JWT authentication
- المفتاح محفوظ بشكل آمن في Supabase Secrets
- لا يتم تخزين الصور في خوادم Anthropic

## الدعم

إذا واجهت أي مشاكل:
1. تحقق من سجلات Edge Function
2. تأكد من وجود ANTHROPIC_API_KEY
3. تحقق من وضوح الصورة المرفوعة
4. راجع Console في المتصفح (F12) للأخطاء
