# دليل نموذج تسجيل الموردين
## Vendor Registration Form Guide

---

## 🎨 نظرة عامة | Overview

تم إنشاء نموذج تسجيل موردين متعدد الخطوات بتصميم حديث واحترافي مستوحى من أفضل ممارسات تجربة المستخدم في شركات الإنتاج.

---

## 🚀 كيفية الوصول | How to Access

للوصول إلى نموذج التسجيل، استخدم أحد الخيارات التالية:

### الخيار 1: عبر الرابط المباشر
```
http://localhost:5173/vendor-registration
```

### الخيار 2: البيئة الإنتاجية
```
https://yourdomain.com/vendor-registration
```

## ✨ المميزات الرئيسية | Key Features

### 🎭 التصميم والحركة
- **خلفية متحركة داكنة** مع تدرجات أنيقة
- **Glass Morphism Cards** بشفافية وتأثيرات ضبابية
- **انتقالات سلسة** بين الخطوات باستخدام Framer Motion
- **Micro Animations** على جميع العناصر التفاعلية
- **Floating Labels** للحقول النصية
- **شريط تقدم متحرك** في أعلى النموذج
- **دعم كامل للغة العربية** (RTL)

### 💾 الوظائف الذكية
- **حفظ تلقائي للمسودات** كل 30 ثانية
- **التحقق من البيانات** لكل خطوة
- **رفع الملفات** بالسحب والإفلات
- **معاينة الصور** قبل الرفع
- **بحث ذكي** في القوائم المنسدلة
- **حالات التحميل** المتحركة

## 📋 الخطوات الست | Six Steps

### الخطوة 1: المعلومات الأساسية
- **الاسم الثلاثي** (مطلوب)
- **الجنسية** (مطلوب - قائمة بحث)
- **المجال الأساسي** (مطلوب - من الإعدادات)
- **نوع المورد** (فرد / شركة - بطاقات اختيار متحركة)

### الخطوة 2: معلومات التواصل
- **رقم الجوال** (مطلوب - مع اختيار كود الدولة)
- **مدينة العمل** (مطلوب - قائمة بحث)
- **متاح في مدن أخرى؟** (Toggle متحرك)
- **اختيار المدن الإضافية** (إذا تم التفعيل)

### الخطوة 3: المستندات الثبوتية
- **رقم الهوية الوطنية** (مطلوب)
- **رفع صورة الهوية** (مطلوب - Drag & Drop)
- **رفع الصورة الشخصية** (مطلوب - معاينة دائرية)

### الخطوة 4: معلومات السفر (اختياري)
- **رقم جواز السفر**
- **دولة التأشيرة** (قائمة بحث مع أعلام الدول)
- **رفع مستند التأشيرة** (صور أو PDF)

### الخطوة 5: المعلومات المالية
- **اسم البنك** (مطلوب - قائمة البنوك السعودية)
- **اسم المستفيد** (مطلوب)
- **رقم الآيبان** (مطلوب - IBAN validation)
- **السعر يشمل الضريبة؟** (Toggle)

### الخطوة 6: المراجعة والإرسال
- **عرض ملخص** لجميع البيانات المدخلة
- **زر تعديل** لكل قسم
- **موافقة على الشروط**
- **إرسال الطلب** النهائي

## 🗄️ قاعدة البيانات | Database

### الجداول المستخدمة:

1. **vendors** - بيانات المورد الأساسية
2. **vendor_travel_documents** - بيانات السفر والتأشيرات
3. **vendor_financial_data** - المعلومات المالية
4. **vendor_registration_drafts** - المسودات (تنتهي بعد 30 يوم)

### التخزين:
- الصور تُحفظ في **Supabase Storage**
- المسارات: `vendor-images/id_images/`, `profile_images/`, `visa_documents/`

## 🛠️ التخصيص | Customization

### تعديل الألوان:
قم بتعديل ملف `/src/styles/vendor-registration.css`

### إضافة حقول:
1. أضف الحقل في `VendorFormData` interface
2. أضف الحقل في الخطوة المناسبة
3. حدّث validation في `validateStep()`
4. حدّث الـ Review في `Step6Review`

### تعديل الرسوم المتحركة:
استخدم Framer Motion props:
```typescript
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ delay: 0.2 }}
>
```
